Каждый .bat запускает winws2 со своей стратегией в этом окне.
Закрыть окно или нажать Ctrl+C - остановить. Либо запустите stop_zapret2.bat.
Общей стратегии нет: пробуйте по порядку 01, 02, 03 ... пока нужные сайты не откроются.
Отладка: перед запуском выполните  set ZAPRET_DEBUG=1  (включит --debug).
