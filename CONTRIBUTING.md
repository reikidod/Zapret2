# Разработка

## Технологии

- C# / WPF / .NET 10.
- `src/Zapret2.Core` — хранение профилей, поиск компонентов, разбор аргументов и управление процессами.
- `src/Zapret2.App` — WPF-интерфейс.
- `tests/Zapret2.Core.Tests` — автоматические тесты.

## Принципы

1. Не менять пользовательские профили и списки без явного действия.
2. Перед заменой конфигурации сохранять резервную копию.
3. Не встраивать `winws2`, WinDivert или чужие бинарные файлы в portable EXE.
4. Не добавлять непроверенные сетевые аргументы в качестве рекомендуемых по умолчанию.
5. Не утверждать совместимость с игрой, прокси или приложением без воспроизводимой проверки.
6. Не скрывать ошибки запуска и остановки процессов.

## Проверки перед отправкой

```powershell
dotnet restore .\Zapret2.sln
dotnet test .\Zapret2.sln --configuration Release
dotnet publish .\src\Zapret2.App\Zapret2.App.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

Для изменений WPF дополнительно проверьте запуск на Windows 10/11, масштабирование DPI и работу при отказе UAC.

## Изменения

- Один PR — одна логически связанная задача.
- В описании укажите причину, затронутые сценарии, тесты и известные ограничения.
- Не прикладывайте реальные пользовательские конфиги, IP-адреса, логи с персональными данными и секреты.
