# Zapret2 Control Center

Windows-приложение с уже встроенным комплектом классического Zapret и Zapret2: `winws.exe`, `winws2.exe`, оба `blockcheck`, WinDivert, Cygwin, Lua, профили и списки Flowseal. Дополнительный bundle скачивать не нужно.

**Стек:** C# · WPF · .NET 10 · Windows x64.

> При сборке в portable EXE встраивается закреплённый комплект `bol-van/zapret-win-bundle` и Flowseal profiles/lists. При первом запуске он распаковывается в `%LOCALAPPDATA%\\Zapret2GUI\\components`. Скачивать компоненты не нужно. Для самого тестирования blockcheck требуется доступ к сети; обновление списков остаётся необязательным.

## Возможности C#-версии

| Раздел | Возможности |
|---|---|
| Обзор | Состояние `winws`, `winws2`, Lua и обоих blockcheck; быстрый запуск и переход к журналу |
| Профили | Восемь примеров, создание, копирование, удаление и восстановление; выбор движка winws/winws2; офлайн-импорт 22 профилей Flowseal |
| Редактор | Импорт аргументов из `.cmd` / `.bat`, подстановка `{BIN}`, `{LUA}`, `{LISTS}`, `{GAMEFILTERTCP}` и `{GAMEFILTERUDP}`, проверка и копирование итоговой команды |
| Перенос настроек | Импорт и экспорт пользовательских профилей в JSON |
| Процессы | Запуск и остановка выбранного `winws` или `winws2`, чтение stdout/stderr до завершения, защита от повторного запуска во время очистки, аварийная остановка при закрытии GUI |
| Проверка запуска | Проверка EXE, Lua и list-зависимостей; перед запуском показываются TCP/UDP-порты, hostlist и ipset, а также предупреждение о глобальных фильтрах |
| Списки | Обновление пяти общих файлов Flowseal, проверка данных до записи, резервные копии и откат; создание и сохранение пользовательских `*-user.txt` |
| Диагностика | Поиск компонентов, PID обнаруженных DPI-процессов, запуск соответствующего `blockcheck.cmd` или `blockcheck2.cmd`; автоматические отдельные журналы приложения и выбранного движка с хранением последних 30 сессий |
| Сохранность | Автоматическая резервная копия `config.json.bak` и восстановление при повреждении основной конфигурации |

## Классические стратегии Flowseal

На странице «Профили» нажмите **«Импортировать 22 стратегии Flowseal (офлайн)»**. Приложение использует встроенные исходные `general.bat`, `general (ALT)`–`ALT13`, `EXP`, `FAKE TLS AUTO` и `SIMPLE FAKE` из [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) по закреплённому commit `ffce9179b2b1f2aeb961f4d17274ada3b6d6bea5`. Текст читается из встроенных локальных файлов; извлекаются только параметры `winws2.exe`, BAT/CMD не исполняются. Пути к `lists` и игровые фильтры разрешаются из выбранного bundle. Если `utils/game_filter.enabled` отсутствует, игровые фильтры отключены, как в Flowseal по умолчанию. Эти профили не являются гарантией совместимости: проверяйте область действия фильтров перед запуском.

## Скачать portable EXE

Постоянная ссылка на автоматически обновляемую сборку: [скачать Zapret2ControlCenter.exe](https://github.com/reikidod/Zapret2/releases/download/continuous/Zapret2ControlCenter.exe). После каждого успешного CI на `main` файл в этом релизе заменяется новой версией. В один EXE встраиваются оба движка, WinDivert, Cygwin, оба blockcheck и Flowseal profiles/lists. Дополнительно сборка сохраняется в GitHub Actions как `Zapret2ControlCenter-Windows-x64`. Устанавливать .NET Runtime не требуется.

EXE не требует распаковки и не записывает пользовательские профили внутрь каталога программы. Настройки находятся в `%APPDATA%\Zapret2GUI` и сохраняются при замене EXE новой версией.

## Требования

- Windows 10/11 x64.
- Все компоненты движков уже встроены в EXE; на первом запуске они автоматически распаковываются в профиль пользователя.
- Для запуска WinDivert обычно нужны права администратора.
- `blockcheck.cmd` и `blockcheck2.cmd` входят в комплект и запускаются для ручной диагностики соответствующего движка.

## Сборка из исходников

Откройте `Zapret2.sln` в Visual Studio с компонентом разработки WPF или выполните в PowerShell:

```powershell
dotnet restore .\Zapret2.sln
dotnet test .\Zapret2.sln --configuration Release
.\build-portable.ps1
```

Результат: `publish\win-x64\Zapret2ControlCenter.exe` — self-contained single-file приложение для Windows x64.

## Ограничения текущей C#-версии

- Результаты `blockcheck.cmd` и `blockcheck2.cmd` пока не разбираются автоматически: соответствующий скрипт открывается в отдельной консоли.
- Журналы сохраняются локально в `%APPDATA%\\Zapret2GUI\\logs`. Они могут содержать пути, домены и IP-адреса из вывода `winws2`; приложение не отправляет их автоматически. Сравнение сессий внутри GUI пока не реализовано.
- Списки загружаются из публичного репозитория [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube). Обновляются только общие `ipset-all.txt`, `ipset-exclude.txt`, `list-general.txt`, `list-google.txt` и `list-exclude.txt`; пользовательские `*-user.txt` создаются отдельно и не заменяются. Старые общие файлы сохраняются в `lists/.backups/`.
- Обновление не выполняет автоматическое слияние локальных правок внутри общих файлов: собственные записи следует хранить в соответствующих `*-user.txt`.
- Выбор профиля не гарантирует совместимость с конкретным приложением или провайдером. Steam, Telegram Proxy, Valorant и другие приложения требуют отдельных проверок на реальной системе.
- Игровые фильтры Flowseal читаются из `utils/game_filter.enabled`; если файла нет, они отключены (значение `12`).
- Классические профили Flowseal импортируются из закреплённого commit `ffce9179b2b1f2aeb961f4d17274ada3b6d6bea5`. Текст BAT читается из встроенного комплекта; извлекаются только аргументы `winws2`, BAT/CMD не выполняются.
- Фильтры по портам не изолируют приложения по имени процесса и могут затрагивать другие программы. Проверяйте область действия профиля перед запуском.
- Встроенные стратегии — примеры, а не универсальные рекомендации.
