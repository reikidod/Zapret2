# Zapret2 Control Center

Portable Windows x64 GUI for managing an existing zapret2 bundle.

## Build

GitHub Actions builds `Zapret2ControlCenter.exe` for Windows x64 and publishes it as a workflow artifact. The application does not bundle `winws2.exe`, WinDivert, Lua, or blockcheck2; provide an existing zapret-win-bundle folder in the app.

See `zapret2-rust-source.zip` for the Rust source snapshot until the source tree is expanded into normal repository files.
