# Zapret2 Control Center

Windows-приложение для управления установленным `zapret2`: выбор профилей, подготовка аргументов `winws2`, запуск и остановка процесса, проверка компонентов и просмотр журнала.

**Стек:** C# · WPF · .NET 10 · Windows x64.

> Приложение — только графическая оболочка. Оно не включает `winws2.exe`, WinDivert, драйверы или сторонний zapret2 bundle. Эти компоненты пользователь устанавливает отдельно из доверенного источника.

## Возможности C#-версии

| Раздел | Возможности |
|---|---|
| Обзор | Состояние `winws2`, Lua-библиотек и `blockcheck2`; быстрый запуск и переход к журналу |
| Профили | Восемь встроенных примеров, создание, копирование, удаление и восстановление встроенных настроек |
| Редактор | Импорт аргументов из `.cmd` / `.bat`, подстановка `{BIN}` и `{LUA}`, проверка и копирование итоговой команды |
| Перенос настроек | Импорт и экспорт пользовательских профилей в JSON |
| Процессы | Запуск и остановка `winws2`, чтение stdout/stderr до завершения, защита от повторного запуска во время очистки, аварийная остановка при закрытии GUI |
| Проверка запуска | Проверка наличия EXE и Lua-файлов, на которые ссылается профиль; предупреждение о глобальных фильтрах портов и возможном влиянии на другие приложения |
| Списки | Обновление пяти общих файлов Flowseal, проверка данных до записи, резервные копии и откат; создание и сохранение пользовательских `*-user.txt` |
| Диагностика | Поиск компонентов, PID обнаруженных DPI-процессов, экспорт журнала, запуск `blockcheck2` в отдельной консоли |
| Сохранность | Автоматическая резервная копия `config.json.bak` и восстановление при повреждении основной конфигурации |

## Скачать portable EXE

Постоянная ссылка на автоматически обновляемую сборку: [скачать Zapret2ControlCenter.exe](https://github.com/reikidod/Zapret2/releases/download/continuous/Zapret2ControlCenter.exe). После каждого успешного CI на `main` файл в этом релизе заменяется новой версией. Дополнительно сборка сохраняется в GitHub Actions как `Zapret2ControlCenter-Windows-x64`. Устанавливать .NET Runtime не требуется.

EXE не требует распаковки и не записывает пользовательские профили внутрь каталога программы. Настройки находятся в `%APPDATA%\Zapret2GUI` и сохраняются при замене EXE новой версией.

## Требования

- Windows 10/11 x64.
- Отдельная совместимая папка zapret2 bundle с `winws2.exe` и необходимыми Lua-файлами.
- Для запуска WinDivert обычно нужны права администратора.
- `blockcheck2.cmd` необязателен и используется только для ручной диагностики.

## Сборка из исходников

Откройте `Zapret2.sln` в Visual Studio с компонентом разработки WPF или выполните в PowerShell:

```powershell
dotnet restore .\Zapret2.sln
dotnet test .\Zapret2.sln --configuration Release
.\build-portable.ps1
```

Результат: `publish\win-x64\Zapret2ControlCenter.exe` — self-contained single-file приложение для Windows x64.

## Ограничения текущей C#-версии

- Результаты `blockcheck2` пока не разбираются автоматически: скрипт открывается в отдельной консоли.
- Списки загружаются из публичного репозитория [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube). Обновляются только общие `ipset-all.txt`, `ipset-exclude.txt`, `list-general.txt`, `list-google.txt` и `list-exclude.txt`; пользовательские `*-user.txt` создаются отдельно и не заменяются. Старые общие файлы сохраняются в `lists/.backups/`.
- Обновление не выполняет автоматическое слияние локальных правок внутри общих файлов: собственные записи следует хранить в соответствующих `*-user.txt`.
- Выбор профиля не гарантирует совместимость с конкретным приложением или провайдером. Steam, Telegram Proxy, Valorant и другие приложения требуют отдельных проверок на реальной системе.
- Встроенные стратегии — примеры, а не универсальные рекомендации.
