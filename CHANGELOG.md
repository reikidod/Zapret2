# Changelog

## Unreleased

- Windows CI run #51: сборка и 41/41 тестов прошли; portable EXE и постоянный релиз `continuous` обновлены.

- Укреплён жизненный цикл `winws2`: ожидание завершения процесса и чтения журнала, защита от повторного запуска во время очистки, аварийное завершение дочернего процесса при закрытии GUI.
- Добавлена предварительная проверка исполняемого файла и Lua-зависимостей профиля.
- Перед запуском профилей с глобальными фильтрами портов показывается предупреждение о возможном влиянии на другие приложения.
- Добавлены автоматические тесты потоков вывода, остановки процесса, Lua-зависимостей и анализа области действия профиля.
- Добавлена страница «Списки»: обновление пяти общих файлов Flowseal, проверка UTF-8/IP/CIDR, резервирование и откат.
- Пользовательские `*-user.txt` создаются отдельно, не заменяются при обновлении и открываются из GUI в Блокноте.
- Добавлено автоматическое сохранение отдельных журналов приложения и `winws2` в `%APPDATA%\\Zapret2GUI\\logs`, с ограничением хранения последними 30 сессиями.
- Добавлены тесты обновления списков, резервных копий и защиты пользовательских файлов.
- Добавлен тест автоматического сохранения журналов и очистки старых сессий.
- Добавлен импорт 22 классических профилей Flowseal из закреплённого commit; исходные BAT/CMD загружаются как текст, но не выполняются.
- Добавлена подстановка `{LISTS}`, `{GAMEFILTERTCP}` и `{GAMEFILTERUDP}` с чтением игровых фильтров из `utils/game_filter.enabled`.
- Предварительная проверка теперь выявляет отсутствующие пользовательские списки, необходимые импортированным профилям.

## 2026-11-27 — C# / WPF migration

### Added
- Перенесено приложение на C# / WPF / .NET 10 в обычную структуру Visual Studio: `src`, `tests`, `assets`.
- Добавлены разделы «Обзор», «Профили», «Диагностика» и «Настройки».
- Перенесены поиск компонентов, редактор аргументов, импорт BAT/CMD, профили, запуск и остановка `winws2`, журнал и ручной запуск `blockcheck2`.
- Сохранена совместимость с JSON-конфигурацией прежней Python GUI.
- Добавлены резервное копирование конфигурации и восстановление из `.bak`.
- Сохранён прежний Rust-архив в `legacy/rust/` для истории и отката.

### Build and release
- Windows x64 solution build: успешно.
- Unit tests: 20/20 успешно.
- Portable publishing: self-contained single-file EXE.
- Добавлен постоянный GitHub Release `continuous`; его EXE и SHA-256 обновляются после успешного CI на `main`.
- Сборка: [GitHub Actions run](https://github.com/reikidod/Zapret2/actions/runs/45930530561).
- Постоянная загрузка: [Zapret2ControlCenter.exe](https://github.com/reikidod/Zapret2/releases/download/continuous/Zapret2ControlCenter.exe).

### Not yet migrated / verified
- Автоматический разбор результатов `blockcheck2` ещё не реализован.
- Обновление общих списков Flowseal с сохранением `*-user.txt` ещё не перенесено.
- Проверка реального запуска на Windows 10/11 с установленным bundle и тесты совместимости Steam, Telegram Proxy, Valorant, Discord и YouTube ещё впереди.
- Встроенные стратегии остаются примерами, а не универсальными рекомендациями.
